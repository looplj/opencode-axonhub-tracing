## OVERVIEW

OpenCode **v2** plugin (`opencode-axonhub-tracing`) — injects `AH-Thread-Id` and `AH-Trace-Id` headers into every LLM request via the `session.hook("model.request")` API. Header keys configurable via env vars. Trace id preserved at per-message granularity by pairing a `prompt` hook with the request hook.

## STRUCTURE

## CONVENTIONS

- Default export only — named exports become extra plugin entrypoints in v2 discovery
- `UPPER_SNAKE_CASE` constants, `camelCase` functions
- No semicolons
- `typeof x === "string"` over `x?.trim()` for env var safety
- Tests use `as any` for mock ctx/events, `afterEach` for env cleanup
- Bun-first: `bun:test`, `bun build`, `bunx tsc`

## ANTI-PATTERNS (THIS PROJECT)

- **NEVER** import from `@opencode-ai/plugin` — that is the v1 package; v2 uses `@opencode/plugin`
- **NEVER** return a `{ "chat.headers": ... }` hook object — v1 shape, silently ignored by v2
- **NEVER** add named exports — keep only the default `Plugin.define(...)`
- **NEVER** assume `event` or `event.headers` exists — guard with `if (!event?.sessionID || !event?.headers) return`
- **NEVER** use `envValue?.trim()` on env vars — use `typeof envValue === "string"` (env values can be non-string at runtime)
- **NEVER** assume `model.request` carries a message id — it only has `sessionID`; capture it in the `prompt` hook

## NOTES

- `bun build ... --external '@opencode/*'` keeps `@opencode/plugin` as a bare import; the host resolves it. Without `--external` the dependency graph is inlined (~255KB).
- `package.json` exposes both `.` and `./server` → `dist/index.js`; v2's `Host.resolve` tries `["server", ""]` subpaths.
- Reference implementation (v1 only, NOT v2-compatible): `looplj/opencode-axonhub-tracing`.
- Plugin signature: `Plugin.define({ id, setup })` where `setup(ctx)` may return a cleanup function.
- Session hook registration shape: `await ctx.session.hook("model.request", (event) => { event.headers[...] = ... }, { providerID })`. The third options arg is only typed (and only honored) for hooks whose event has a `model` field.
- Thread ID = `event.sessionID`, Trace ID = latest `messageID` recorded by the `prompt` hook (only injected when present).
